# Delta revival

## Goal
Ship a polished macOS branching-conversation app without replacing its canvas/chat identity or losing existing data.

## Approved scope
- macOS only; Windows/Linux deferred.
- Prepare a signed, notarized GitHub draft release. Never publish without Dan's approval.
- README roadmap is the complete backlog.
- Preserve conversations, attachments and migration history. Keep Electron/React and SQLite/Knex.
- Discover models from providers, not a frozen catalog. Support OpenAI, Anthropic, Google, Ollama and configurable OpenAI-compatible endpoints.

## Done looks like
- Reproducible install, typecheck, lint, boundary tests and packaged-app smoke tests pass.
- Fresh startup and upgrade from the original database work.
- Branch/edit/regenerate, streaming cancellation, errors, search, image attachments and exports work.
- Secrets never cross the read-settings IPC boundary or enter logs; old plaintext keys migrate to OS-protected encrypted storage.
- Settings, model search/provider visibility, documented configurable shortcuts, spellcheck and full-library backup are usable.
- Release script verifies signing, notarization, stapling and checksums before uploading a draft.

## Implementation
1. Pin toolchain and dependencies; add tests and CI.
2. Shared typed IPC/messages; explicit provider adapters and paginated model discovery with timeouts, cache and manual IDs.
3. Separate ~/.config/delta/config.json from Keychain-backed Electron safeStorage secrets. Preserve legacy data path.
4. Await persistence before stream completion; isolate requests, abort upstream work and retain partial results.
5. Transactional subtree deletion, safe search, backup, startup and renderer hardening.
6. Refine existing screens, not a redesign. Verify light/dark/compact states with synthetic data.
7. macOS arm64/x64 build scripts, Developer ID signing, notarization and GitHub draft workflow.

## Backlog decisions
- Retain Knex: its migration ledger already protects user data; fix typing and broken administrative calls instead of switching frameworks.
- Summaries remain explicit/on-demand, not hidden extra paid calls.
- No Windows/Linux release claims or automatic updates in this release.

## Verification / progress
Implementation and local verification completed. See docs/RELEASE.md for coverage and release procedure. Apple silicon is the initial draft target; native Intel verification and signing-runner registration remain operator follow-ups. Linux/Windows are deferred. Source and release publication require explicit approval.

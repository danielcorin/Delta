# Delta 0.2.0

Delta is a local-first Mac app for branching conversations with AI models.

- Discover models directly from OpenAI, Anthropic, Google and Ollama.
- Connect an OpenAI-compatible server, including local servers.
- Search the model picker, hide providers, refresh catalogs and add model IDs manually.
- Branch by editing or regenerating a message. Stop an in-progress response and keep its partial text.
- Keep API keys in macOS Keychain-backed encrypted storage. Older plaintext keys migrate automatically.
- Search conversations, attach or paste images, export chats and Obsidian canvases, and back up the full library.
- Refined light/dark layouts, resizable canvas, keyboard shortcuts and native spellchecking.
- Scroll over collapsed nodes to control the canvas. Expand a prompt or response to scroll its content, including sideways through code blocks.
- A native Liquid Glass river/tree icon with layered default, dark and tinted appearances on macOS 26+, plus an older-macOS fallback.

## Install

Download the arm64 DMG for Apple silicon, open it, and drag Delta to Applications. The app and disk image are Developer ID-signed and notarized. macOS 14 or later.

## Verification notes

The Apple silicon build is verified locally. Intel packaging is implemented but requires its native CI runner before an Intel download is offered. Windows and Linux are deferred.

Cloud provider discovery and adapters have automated fixture coverage, not live paid-account verification. Provider availability, account access, image support and sampling controls vary by model. Local semantic search requires Ollama with nomic-embed-text.

The attached manifest identifies the exact source commit. No automatic updater is included.

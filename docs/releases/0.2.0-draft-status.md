# Delta 0.2.0 release candidate

The app modernization is implemented and locally tested. This is a private draft, not a published release.

## Verified

- Strict TypeScript, lint and 26 boundary tests.
- Hidden-window Electron tests covering chat, editing/branching, cancellation, pasted images, provider errors, model search, settings, library search and backup integrity.
- Native Apple silicon Developer ID-signed launch, SQLite vector extension and renderer bridge.
- Dependency audit with zero reported vulnerabilities.

## Before publishing

Apple notarization requires a valid notarytool Keychain profile. The expected profile is DeltaNotary, or set NOTARY_PROFILE to an existing profile. Distribution assets will be uploaded only after notarization, stapling and Gatekeeper assessment succeed.

Intel packaging is implemented but still needs native-runner verification. Windows/Linux are deferred. Cloud provider protocols use local test fixtures; live paid-account verification remains a manual check.

The source changes remain on the local revive-delta branch until publication is approved. The release pipeline uploads a matching source archive and manifest with the verified artifacts before publishing.
